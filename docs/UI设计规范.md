# miniboos UI设计规范 v2.1

> 参照系：**BOSS直聘** | v2.0实地测绘版；**v2.1修正（2026-09-16深夜双平台复测）：职位名为深黑非青色**，青色只管交互

## 一、实测设计密码（BOSS三色系统）

```
深黑 #222222 → 职位名/标题正文（2026-09-16深夜复测：PC版a.name与移动版均rgb(34,34,34) 16px/500）
青色 #00A6A7 → 只管交互：按钮/链接hover/激活态（职位名hover变青）
红橙 #FE574A → 只管钱：薪资是全场唯一暖色强调，20px大字
灰阶 → 其他一切：文字直排标签 #414A60、公司名 #666、底色 #F2F4F7
```

**克制原则：一屏最多一个暖色元素（薪资），青色只用于可点击。**
**v4教训补充：v2.0曾误记"职位名青色"（可能测到hover态），青色职位名导致整屏偏花——复测纠偏。**
