# miniboos UI设计规范 v2.0

> 参照系：**BOSS直聘** | 本版为**实地测绘版**（2026-09-16浏览器实测zhipin.com职位列表页计算样式，非脑补）

## 一、实测设计密码（BOSS三色系统）

```
青色 #00A6A7 → 管一切交互：职位名/按钮/链接/激活态
红橙 #FE574A → 只管钱：薪资是全场唯一暖色强调，20px大字
灰阶 → 其他一切：文字直排标签 #414A60、公司名 #666、底色 #F2F4F7
```

**克制原则：一屏最多一个暖色元素（薪资），青色只用于可点击。**

## 三、关键页规范（实测翻译）

| 页面 | 规范 |
|---|---|
| 职位列表 | 行1：青色职位名16px/500 + 红橙薪资20px右对齐；行2：蓝灰标签·分隔直排；行3：灰公司名。白卡12px |
| 职位详情 | 白卡头（黑职位名21px+红橙薪资22px）、公司独立卡、青色"一键投递"按钮 |

| 会话 | 我方青色实色气泡、对方白气泡，12px圆角 |
| Admin | 青色主色统计卡/菜单激活，白侧边栏 |
