# miniboos UI设计规范 v3.0

> 参照系：**BOSS直聘（双平台实测）+ CEO两轮验收定稿（2026-09-17）**
> 版本史：v2.0实地测绘 → v2.1职位名深黑修正 → **v3.0两轮验收全套定稿**（标签chips化/头像卡/导航收纳/登录区分/图标规范）

## 一、实测设计密码（BOSS三色系统）

```
深黑 #222222 → 职位名/标题正文（实测PC版a.name与移动版均rgb(34,34,34) 16px/500）
青色 #00A6A7 → 只管交互：按钮/链接hover/激活态/FAB/菜单图标
红橙 #FE574A → 只管钱：薪资是全场唯一暖色强调，20px大字
灰阶 → 其他一切：标签字#666、公司名#666、页面底#F2F4F7
```

**克制原则：一屏最多一个暖色元素（薪资），青色只用于可点击，图标禁用emoji。**

## 三、组件规范（定稿）

| 组件 | 规范 |
|---|---|
| 职位卡（列表） | 行1：职位名16px/500 + 薪资20px右对齐；行2：**chips标签**（类别/城市/学历，浅灰底小标签）；行3：公司12px灰。卡间距14px |
| 个人卡（简历页） | 头像64×86左（无照片=user-o灰icon）+ **"更换照片/上传照片"直白小字**（禁用无语义角标）；右侧姓名20px/600可编辑 + 属性行12px灰（期望方向·城市·薪资） |
| FAB发布按钮 | 青色胶囊48px高、带"发布"文字（纯图标禁用——可发现性） |
| 导航收纳（跨端统一） | 次要功能（退出登录/企业认证）→ **右上角apps-o图标22px青色 → action-sheet**（退出登录红色）。tabbar只放核心导航，二级页面不进tabbar |
| 登录页（C端） | 4px亮青顶条 + user-o青icon圆 + miniboos + 青底「牛人端」徽章 + slogan |
| 登录页（B端） | 4px**深青**顶条 + shop-o深青icon圆 + **深青底「招聘端」徽章**——色彩+图标语义双通道区分 |
| 表单textarea | 自适应一行起（`autosize {minHeight:44}`），禁固定多行高（假空隙） |
| Admin图标 | Element Plus线性图标统一（禁emoji），纯青#00a6a7无渐变，light系列用#00a6a7衍生（`#4cc5c6/#80d4d5/#b3e7e8/#d9f2f2/#ecf8f8`） |

## 五、验收口径

1. **并排对照法**：与BOSS同类页并排（zhipin.com实测值为准），外行扫一眼不觉得廉价
2. 不达标须指认违反本规范哪条token/组件规范
3. **视觉模型初审+DOM核实双通道**：看图提线索、DOM下结论（实战：视觉初审3条误报全靠DOM纠正）
4. 图标可识别性：用户"看不懂"的视觉元素=删除或换直白方案

## 六、工程保险（CSS）

```css
/* 滚动保险：嵌入webview（如IAB）会给html/body/#app设固定高导致溢出不可滚，必须显式解锁 */
html, body, #app { height: auto !important; min-height: 100% !important; }
```
