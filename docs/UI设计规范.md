# miniboos UI设计规范 v1.0

> 参照系：**BOSS直聘**（CEO拍板 2026-09-16） | 验收尺子：本文档

## 一、设计原则

1. **BOSS绿品牌系**：主色绿+白底，行业认知零成本
2. **信息优先**：招聘产品用户要快——职位名/薪资/公司三要素一屏可扫
3. **扁平紧凑**：卡片小圆角浅阴影，信息密度优先于留白艺术
4. **三端同源**：C端/B端/Admin共用一套token，改一处换全身

## 二、Design Token（v3·BOSS绿）

| Token | 值 | 用途 |
|---|---|---|
| 主色 | `#00b96b` | 按钮/链接/激活态 |
| 主渐变 | `135° #00d68f→#00b96b` | 导航栏/主按钮/登录页 |
| 薪资色 | `#00b96b`（同主色） | **BOSS惯例：薪资绿大字** |
| 背景 | `#f6f7f8` | 页面底色 |
| 主文字 | `#222327` 粗 | 标题 |
| 次文字 | `#7e8794` | 辅助信息 |
| 圆角 | `10px`（卡片）/胶囊（按钮） | 扁平不臃肿 |
| 阴影 | `0 2px 8px rgba(34,35,39,.05)` | 存在感刚好 |

## 三、关键页规范

| 页面 | 规范要点 |
|---|---|
| 登录页 | 品牌渐变天空+下圆角弧+上浮白卡；logo白色粗体 |
| 职位列表 | 白卡紧凑排列；**职位名粗黑+薪资绿右对齐同字号**；灰底小方角标签；意向匹配=渐变标签 |
| 职位详情 | 渐变头部（职位名+大号绿薪资+半透明白标签）；企业独立卡片；绿色主按钮"一键投递" |
| 会话 | 我方渐变气泡（带尾）、对方白卡气泡；输入条底部悬浮 |
| 简历表单 | 白卡分组（基本信息/意向/经历）；意向=字典下拉；发布=显式主按钮 |
| Admin | 白侧边栏+圆角菜单胶囊+渐变图标徽章统计卡；表格圆角 |

## 四、微交互

- 按钮按下：卡片背景微变（:active），不用大幅缩放
- 发布成功：🎉 toast反馈
